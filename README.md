# NO-FuelBurnEnduranceTimer
Mod for Nuclear Option - Shows you how much time you have until the engines flame out from fuel starvation, accounting to your current throttle level, and quantity of fuel onboard. Calculates fuel burn rate and displays an endurance timer with said values. Updates every second.
